Sistema de Ventas

Aplicación web desarrollada con Spring Boot, Thymeleaf y MySQL para la gestión integral de un negocio.

Funcionalidades:
El sistema permite administrar:

1. Usuarios.
2. Clientes.
3. Productos.
4. Ventas.
5. Detalle de ventas.

Cada una con sus respectivos metodos Agregar, Eliminar y Editar de manera funcional.
 
Autenticación:
1. Un login con validación de credenciales.
2. Registro de usuarios (rol USER por defecto).
3. Solo puede existir un ADMIN.
4. Manejo de inicio y cierre de sesión.

Base de datos (SQL):
1. Creación de entidades (tablas).
2. Procedimientos almacenados
3. Relaciones con llaves foráneas
4. Eliminación en cascada

Se hizo uso de las siguientes herramientas/lenguajes/frameworks:
1. Java
2. Spring Boot
3. Spring MVC
4. Thymeleaf
5. JPA / Hibernate
6. MySQL
7. HTML / CSS

Estructura: 

1. Controller/
2. Service/
3. Repository/
4. Entity/
5. templates/ .html
6. static/ images (.png) y styles (.css)
